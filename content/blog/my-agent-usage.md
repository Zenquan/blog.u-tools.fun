# 我的 Agent 怎么使用：WorkBuddy 个人工作台实战拆解

经常有人问我：「你天天说自己在用 Agent，你到底是怎么用的？」

问多了，我干脆画了一张图——《你的 WorkBuddy 个人工作台》。这篇文章就是这张图的文字版，按「输入层 → 核心引擎 → 产出层」三层，把我实际的使用方式完整交代一遍。

![WorkBuddy 个人工作台](/static/blog/my-agent-usage/workbench.png)

---

## ① 输入层：一句话就能开跑

我几乎不打开 Agent 专门「操作」什么。日常的做法是**四种入口随便丢**，剩下交给它：

| 入口 | 我的实际用法 |
|------|-------------|
| **一句话指令** | 自然语言直接下达，不用学什么命令格式。比如「把上周那篇引流文改成长图版封面」 |
| **微信文章链接** | 丢一个链接即改即推——看到一篇好文章，直接扔给它，改写、配图、存草稿一条龙 |
| **文件 / 截图** | 素材直接丢进来：截图、PDF、本地文档，它自己会识别内容再干活 |
| **定时触发** | 到点自动跑，不用我盯。每天固定时间的选题检查、数据回流都挂在定时器上 |

**心得**：输入层设计得越「像聊天」，我用得越勤。因为不需要先想清楚「这个需求该走哪个功能」，凡是脑子里冒出来的念头都能直接变成一次执行。丢东西 > 下命令 > 记定时，是我实际的使用频率排序。

---

## ② 核心引擎：五大支柱（我全部在用）

图里这五个支柱不是概念，是我每天都在跑的五个实际模块：

### 1. Skills 技能库——能力是攒出来的

技能库是我最常扩容的地方，目前常用的几个：

- **wechat-app-rewriter**：公众号文章改写专用技能，丢链接进去就走「拆结构 → 换角度 → 重写」流程；
- **md-wechat-theme**：主题生成技能，按文章内容生成适配公众号的 Markdown 排版主题；
- **pil-cover**：微信封面生成技能，出图直接用，不用再开设计工具；
- **wechat-draft-push**：直接把产物推进公众号草稿箱，省掉所有手工复制粘贴；
- **wechat-new-account-growth**：新号成长技能，冷启动阶段按它给的节奏和打法走；
- **21 个开发技能**：开发侧能力，写小程序、查 bug、review 代码都走这里；
- **热词分析**：追选题用的，喂一批素材就能输出热词和角度。

### 2. 自动化——能定时就不手动

主要挂两类：**定时发文**（到点自动推草稿/发布）和**数据回流**（每天定时拉公众号数据回来，不用我记得去看）。

### 3. 项目记忆——把「我的规矩」教给它一次

这是我最看重的一根支柱。我把两条东西固化在项目记忆里：

- **红线**：什么能写、什么不能碰，写成确定性规则喂给它，每次执行都会遵守；
- **选题粮仓**：平时攒下的选题池子，它写稿时自动从里面挑、往里面存，不会每次从零开始想。

**心得**：没有项目记忆的 Agent 是「每次对话都失忆」的临时工；有记忆的才是长期共事的人。规则写进去一次，后面每一篇产出都自动符合我的边界。

### 4. 连接器——让它能碰到真实世界

Agent 自己不出数据，全靠连接器：

- **微信 API**：读写草稿、发文、拉数据都走它；
- **图床**：封面图、文章配图自动上传，产出直接是能用的链接；
- **ima**：知识库侧的连接，检索素材来源。

### 5. 专家——垂直场景开大号

核心是**公众号运营专家**：它知道公众号的选题、标题、排版、发布节奏怎么配，我不用每次写一大段 prompt 交代「公众号应该怎么运营」，它天然带着这套背景知识。

**心得**：五大支柱的分工其实一句话就能说清——**技能管「会做什么」，自动化管「什么时候做」，记忆管「按什么规矩做」，连接器管「碰得到什么」，专家管「做得像不像专业的」**。

## ③ 产出层：可验收的成果

最后这层是我判断「这 Agent 有没有用」的唯一标准——它给的必须是**能直接验收的成果**，不是「我帮你查了查」：

| 产出 | 形态 | 验收标准 |
|------|------|---------|
| **公众号内容** | 文章 / 封面 / 草稿 | 草稿躺在公众号后台，点开就能发 |
| **分析报告** | 热词 / 竞品洞察 | 有结论、有数据、能直接指导下一篇写什么 |
| **小程序代码** | TDD 迭代发布 | 代码可跑、测试通过、能正常发布 |
| **数据回流** | 24h 阅读曲线 | 每天自动更新，我只看趋势不改表格 |

---

## 一个完整闭环的样例

把三层串起来，我的日常长这样：

> 晚上刷到一篇不错的行业分析 → **丢链接**（输入层）→ 技能库里的 **wechat-app-rewriter** 按我的**红线**改写，从**选题粮仓**挑个角度（核心引擎）→ 产物经 **wechat-draft-push** 推进公众号**草稿箱**，封面走**图床**（产出层）→ 第二天早上定时发布 → 第三天 **24h 阅读曲线**自动回流，告诉我这篇值不值得追同类（数据回流 → 再喂回选题粮仓）。

整个链路里我只做了一件事：**丢了个链接**。剩下的决策和执行，都在这个工作台里自动完成了。

---

## 结尾：Agent 不是替我，是替我做「重复」

最后说点个人感受。用了一段时间后我最大的体会是：**Agent 的价值不在「替你思考」，而在「替你执行那些已经有规则的重复」**——改写有流程、发布有时点、数据有口径，这些规则确定的事，交给工作台跑，比我自己跑快得多、还不会忘。

而思考（这篇要不要追、这个角度行不行）永远留给我自己。

这就是我现在的用法。图会不定期更新，等五大支柱再长出新的能力，我再来更新这篇。
